## 3. 🔴 CPO 분기표 — **데이터로 고른다**

```
① 국내 후보가 충분함                     → ❌ **아니다**
   상품당 **1~4건** 이고 그 전부가 **AI URL 풀** 산출이다. 등록부 경로는 **0**.
② 국내 후보 자체가 없음 → 발견 단계 문제   → 🟡 **여기에 가장 가깝다**
   「0」은 아니지만 **공급자가 하나뿐이고 양이 1~4건** 이다. 등록부는 그 상품을 안 판다.
③ 후보는 있는데 전부 SIMILAR/CONFLICT     → ❌ 아니다(S1 beaumonde·S2 biskuit 가 PRESUMED_SAME)
④ SAME 후보가 있는데 UI 에 안 보임        → 🟡 **국내는 아니고 «해외» 에서 4건 성립**
   S1 rboutique(⑧ 제외) · cissywears(샵 2순위) · S2 stockmann(⑧) · bornyesterdaykids(⑧)
   🔴 **국내 Human SAME 은 2/2 가 보인다** ⟹ 「국내가 안 보인다」의 원인은 **노출이 아니라 공급** 이다
```

🔴🔴 **그래서 CEO 가 화면에서 느낀 것의 실체**: 국내 후보가 S2 에 **1건**, S1 에 4건인데 그중
둘은 CONFLICT, 하나는 목록 페이지다 ⟹ **화면에 국내 비교가 사실상 한 줄** 이다.
🔴 「목록을 더 잘 보여주는」 문제가 아니라 **「국내 후보가 1~2건밖에 없는」** 문제다.
