## 3. 🔴🔴 그래서 이번 측정이 가리키는 상한은 **Registry 가 아니다**

```
AI 가 준 13개 URL 중 **상품 상세 URL 은 5개** 이고 나머지는 전부
  브랜드 페이지 · 컬렉션 · 홈 · 가이드 글 · 중고 키워드 페이지 · 쿠팡 샵 링크
🟢 그 탈락은 **올바르다** — 운영 추출기/`classifyUrlShape` 가 목록·홈을 걸러냈다
   (WU-073 이 기록한 「한국 CMS 목록이 PRODUCT_PAGE 로 통과」 유형은 **이번엔 없었다**)
🔴🔴 ⟹ 관측된 병목은 **「한국어 검색이 상품 상세 URL 을 거의 돌려주지 않는다」** 다.
   국내 동일상품을 **파는 샵 이름은 나오는데**(보몽드 · 도노키즈 · 크로켓 · OCO · 쿠팡)
   그 샵의 **상품 상세 URL 이 검색 결과에 없다.**
🔴 **일반화하지 않는다** — 원상품 **2개 · 질의 2건** 이다(§5-B).
```

🟡 **그리고 「샵 이름은 나왔다」는 사실은 버리지 않는다** — `donokids.com` 과
`beaumonde.co.kr` 은 **이미 후보 풀에 있던 샵** 이고(WU-063/112), `croket.co.kr` ·
`ocokorea.com` · 쿠팡은 **등록부 밖 또는 포털** 이다. 🔴 그 샵들의 상세 URL 을
**내가 추측해 만들지 않았다**(URL 을 지어내는 것은 이 트랙의 금지 행위다).
