## 3. 클릭 — **1회**

```
① 위 상품 화면을 연다                          (호출 없음)
② 「시장 분석 / 국내 가격」 영역을 펼친다        (호출 없음)
③ 영역 아래쪽의  🔄 **다시 분석**  을 **한 번** 누른다   ← 🔴 **여기가 유일한 클릭**
④ 결과가 뜨면 **멈춘다.** 다시 누르지 않는다.
```

🔴 **「다시 분석」을 두 번 누르지 마십시오.** 응답이 느려 보여도 기다려 주십시오
(국내 판매처 조회까지 포함해 **1~2분** 걸릴 수 있습니다).

## 4. 기대 화면 — 무엇이 보여야 하나

### 🟢 보이면 정상

```
① 기존 화면이 그대로 있다 — 판매 판정(🟢/🟡/🔴) · 국내 후보 · 가격
② 「다시 분석」 결과 한 줄이 뜬다
③ 그 아래 **새 구역** 이 나타난다:

     🔎 웹 검색 후보 N건
     이번 확인에만 쓰이고 저장되지 않습니다.
     이 후보 정보는 국내 최저가 및 판매판정에 영향을 주지 않습니다.
       ─ SAME 또는 PRESUMED_SAME 등 판정  ·  [국내] 또는 [해외] 또는 (표시 없음)
         ·  가격(예: KRW 74,000 / EUR 75) 또는 「가격 미확인」
         ·  판매처 도메인(클릭하면 열립니다)  ·  판정 근거 한 줄
```

🟢 **참고(사전 실측값 · 같은 상품)**: 트렌비 **SAME** · 머스트잇 **PRESUMED_SAME
(KRW 74,000)** 이 나왔습니다. 🔴 Production 에서 **똑같이 나온다는 보장은 없습니다** —
다르게 나와도 그 자체가 FAIL 은 아닙니다(§5 기준으로 판정합니다).

### 🔴 보이지 않아도 FAIL 이 아닌 것

```
· 「웹 검색 후보」 구역이 **안 나타난다** → 후보를 못 찾은 것일 수 있습니다(정상 가능)
· 「GO/추천」이 뜨지 않는다 → **정상입니다.** 이 상품은 가격 증거가 부족합니다
```

## 5. PASS / FAIL 기준

| | PASS | 🔴 FAIL |
|---|---|---|
| 기존 화면 | 판정·국내 가격이 **그대로** | 클릭 전과 **국내 최저가가 달라졌다** |
| 판매 판정 | 클릭 전과 **같다** | 🟢 추천 ↔ 🟡 조건부 가 **뒤바뀌었다** |
| 새 구역 문구 | 위 두 문장이 **둘 다 보인다** | 문구 없이 후보만 보인다 |
| 통화 | `EUR 75` 처럼 **원래 통화 그대로** | 해외 가격이 **원화로 바뀌어** 보인다 |
| 가격 없음 | **「가격 미확인」** | `0원` · `-` 로 보인다 |
| 시장 | 「국내」/「해외」 또는 **표시 없음** | 근거 없이 **「국내」로 단정** |
| 등록 | 등록 버튼 상태가 **그대로** | 등록 가능/불가가 **바뀌었다** |
| 오류 | 없음 | 화면이 깨지거나 500 오류 |

🔴 **FAIL 이 보이면 거기서 멈추고 그대로 알려 주십시오.** 다시 누르지 마십시오.
