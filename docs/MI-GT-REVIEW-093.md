## 9. 🔴🔴🔴 **가장 중요한 발견 — 셋이 «구별 불가» 하다**

```
S1-1 human SAME       sys SIMILAR / very_high / 축 3
S1-4 human SAME       sys SIMILAR / very_high / 축 3
S1-5 human DIFFERENT  sys SIMILAR / very_high / 축 3

축 문자열이 **셋 다 글자 그대로 같다**:
  ["근거: 핵심 상품명 일부 보보쇼즈", "근거: 상품군 TOP↔TOP", "보류: 브랜드 비스킷 ↔ BOBO CHOSES"]
```

🔴🔴 **그러므로 「문턱을 낮춰 2건을 살린다」는 곧 「S1-5 도 같이 연다」 다.**
⟹ 회복 2 · **False SAME +1** · precision **2/3 = 66.7%**.
🔴 이것은 WU-063~080 이 **여덟 축에서 반복 측정한 그 패턴** 과 **같다**.
   (「완화 = Human DIFFERENT 동반 개방」) — **아홉 번째 재현** 이다.

### 🔴 가를 수 있는 신호가 «있는가» — 전수 확인

| 축 | S1-1 (SAME) | S1-4 (SAME) | S1-5 (DIFF) | 가를 수 있나 |

| 상품코드 | null | null | null | 🔴 **없다** |
| 색상 | null | null | null | 🔴 **없다** (CEO 사유가 「색상 다름」인데 **그 칸이 비어 있다**) |
