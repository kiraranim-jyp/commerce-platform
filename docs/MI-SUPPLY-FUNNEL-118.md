## 3. 🟢🟢 CPO 질문의 답 — **사람이 SAME 이라 한 URL 은 풀에서 «떨어지지 않는다»**

Human SAME URL 을 **그대로 다시 투입** 했다:

| | 투입 | accepted | 상품 확인 | **후보 등록** | 탈락 |
|---|---:|---:|---:|---:|---|
| S1 | 9 | 9 | **9** | **9** | 🟢 **없음** |
| S2 | 10 | 10 | **10** | **10** | 🟢 **없음** |

```
🟢🟢 **전건 생존(19/19).** 풀·분류기·fetch·상품확인 어디에서도 떨어지지 않는다.
⟹ 🔴🔴 **그래서 「왜 다음에는 또 못 찾나」의 원인은 파이프라인이 아니다 —
   그 URL 이 «다음 검색 결과에 다시 나오지 않는» 것이다.**
🔴 지금 구조는 **매번 검색부터 처음 시작한다** — 사람이 확정한 SAME URL 을
   다음 조사의 입력으로 **재사용하는 경로가 없다**(코드에 그 소비자가 0).
```

🔴🔴 **그런데 그 재사용이 곧바로 금지와 만난다** — §12-0 금지 7항에 **「외부 URL 영구 저장 ❌」**
이 있고, 지금 transient 계약(`transient-candidates.ts`)이 **그것을 코드로 막고 있다**.
⟹ 🔴 **CTO 가 임의로 열지 않았다.** 이것은 **제품 정책 결정** 이다(CPO 판정 사안).

🟡 **선택지를 적어만 둔다**(CTO 가 고르지 않았다):
