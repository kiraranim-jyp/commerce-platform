> 🔴 CPO 2026-10-20: 「CTO 검토 화면 ≠ 따져 실물. **어느 단계에서 사라지는지** 를 잡아라.
> 국내가 조회 자체가 안 되는 문제를 **핵심 미해결** 로 다시 올린다.」

# [WU-126 완료 보고]

## 1. 🔴🔴 **원인이 코드로 확정됐다 — 「입력 배선」이다**

```
자동 1회차(상품을 열면 도는 분석) — pipeline/page.tsx:478
   POST /api/price-history/check   body = **{ snapshotId }** 뿐이다
check route — route.ts:36·55·65
   body 는 `{ snapshotId?, **candidateUrls?** }` 를 받는다
   ⟹ 🔴🔴 `candidateUrls` 가 **없으면 AI URL 후보 풀이 «아예 돌지 않는다»**
국내 후보의 출처 — WU-114 실측
   국내 후보 3건(biskuit · beaumonde …)은 **전부 AI URL 풀 산출** 이다
   등록부 검색 경로는 같은 상품에서 **후보 0**(6샵 정상 응답 · 그 상품을 안 판다)
⟹ 🔴🔴 **따져를 열면 국내 후보가 «구조적으로» 0 이다.**
   「조회가 안 된다」는 **정확한 관측** 이고 **버그 리포트가 아니라 설계 상태** 다.
```

🔴🔴 **그리고 내 검토 화면이 왜 달랐는지도 같은 이유다** — 하니스는 **AI 답변 URL 을 직접
넣어** 돌렸다. 즉 **「CTO 검토 화면 정상」은 「따져 정상」을 증명하지 못한다**(CPO 지적 그대로).
🔴 앞으로 그렇게 보고하지 않는다.

## 2. 🟢 각 단계의 실제 상태 (국내)

| 단계 | 상태 |
|---|---|
| ① AI 가 국내 후보를 발견 | 🟡 **S1 6 · S2 4개**(적지만 있다 · WU-118) |
| ② 후보 풀 등록 | 🔴 **자동 분석에서는 입력이 없어 0** — 사람이 URL 을 넣은 경우에만 돈다 |
| ③ MI 통과 | 🟢 넣으면 통과한다(Human SAME URL **19/19 생존** · WU-118) |
| ④ `/pipeline` 응답 | 🟡 **POST 응답에만** 실린다(GET 은 transient 를 넘기지 않는다 · WU-049/056) |
| ⑤ 화면 표시 | 🔴 자동 1회차가 ②를 못 만들므로 **표시할 것이 없다** |

```
🟢 WU-082 가 ④를 고쳤다(응답을 읽는다) — 🔴 그러나 ②가 비어 있으면 읽을 것이 없다.
🔴 그래서 WU-082 는 **틀리지 않았고 충분하지도 않았다**.
```

## 3. 🔴 CTO 가 고치지 않은 이유 — **「AI 답변을 어디서 가져오는가」가 제품 정책이다**

```
`candidateUrls` 는 **셀러가 AI 답변을 붙여넣는** 입력이다(§12 의 「직접 입력 후보(일시)」).
🔴 자동 1회차가 그것을 **스스로 만들 방법이 현재 없다** —
   ⒜ Gemini API 는 **flag OFF · 비용 미승인**(§12 HOLD)
   ⒝ 외부 AI API 전면 제외(§12 확정)
   ⒞ 저장된 AI 답변 재사용은 **WU-119 의 `SNAPSHOT REUSE POLICY CONFLICT`** 에 걸린다
⟹ 🔴 **셋 다 CPO/CEO 결정이다.** CTO 가 배선을 임의로 만들지 않았다.
🟡 유일하게 정책 충돌이 없는 즉시 수단은 **셀러가 「🔄 다시 분석」에 URL 을 넣는 것** 이고,
   그것은 **이미 작동한다**(WU-085/086 실측).
```
