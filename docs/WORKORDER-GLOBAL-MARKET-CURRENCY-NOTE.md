## 3. 🟢 제안 — **문구 + 발화 조건을 관측 데이터에서 유도한다**

### 3-1 발화 조건 (새 데이터 **0** · 카드가 이미 들고 있는 `rows` 만 본다)

```
서로 다른 **시장 지역** 이 2개 이상인데 관측 **통화가 한 종류** 다
   지역 = `parseMarketRegion(marketCode)`  🟢 카드가 이름·국기에 **이미 쓰는 함수** 다
   🔴 `en-int` 는 지역이 **없다**(국가가 아니다) ⟹ 지역 수에 세지 않는다
   🔴 지역이 1개 이하면 **발화하지 않는다** — 한 줄로는 「통화가 시장을 따라가는가」를
      말할 수 없다(모르면 말하지 않는다)
```

🟢 **운영 DB 전수로 검증했다**(`MARKET_PROBE` 행 · 판매처 8곳):

| 판매처 | 행 | 지역 | 통화 | 발화 |
|---|---:|---:|---:|---|
| `www.smallable.com` | 4 | **4** | **1** | 🔴 **발화** |
| `bobochoses.com` | 4 | 3 | 2 | 🟢 안 함 |
| `louisemisha.com` | 6 | 6 | 6 | 🟢 안 함 |
| `www.junioredition.com` | 3 | 1 | 3 | 🟢 안 함 |
| `bobochoses.co.jp` · `luksusbaby.kr` · `main-story.com` · `www.wynken.co.uk` | 1 | 0 | 1 | 🟢 안 함 |

⟹ 🟢 **정확히 Smallable 하나에만 걸린다** · 🟢 **호스트 목록 0 · 등록부 참조 0 · 하드코딩 0.**

### 3-2 문구 (CPO 원칙 5개를 전수 대조해 다듬었다)

```
팝오버 안 · 나라 줄 목록 **바로 위** 한 줄:

   가격 기준 통화 EUR · 배송국가를 지정해 조회한 가격입니다(현지통화 가격이 아닙니다)
```

🔴 **「EUR」은 리터럴이 아니라 관측된 통화에서 온다** — 그 판매처의 단일 통화 값을 쓴다
(다음에 GBP 단일 판매처가 생기면 그 글자가 GBP 가 된다 · 사본 금지).

🔴 **「배송국가별 가격」을 「배송국가를 지정해 조회한 가격」으로 바꿨다.** 이유:
```
CPO 원칙 — 「배송 가능 여부가 검증되지 않았다면 **배송 가능하다고 표현하지 않습니다**」
🔴 그리고 Smallable 경로에는 **배송 가능 국가 가드가 없다**(백로그 2 · Bobo 의
   `marketMayBeObserved` 상당물이 없다) ⟹ 우리는 Smallable 이 JP 로 배송하는지 **모른다**.
🔴 「배송국가별 가격」은 「그 나라에 배송된다」로 읽힌다 ⟹ 검증 안 된 사실을 말하게 된다.
🟢 「배송국가를 **지정해 조회한** 가격」은 **우리가 한 행위** 만 말한다(참이다).
```

🟢 **환산 축은 추가 문구가 필요 없다** — `≈ ₩` 는 이미 작게·흐리게·뒤에 서고
(`GlobalMarketRowView` 주석이 그 이유를 적는다) 카드는 환산을 **만들지 않는다**.
🔴 「환율 환산값을 현지 시장가격처럼 표시하지 않는다」는 **현재 코드에서 이미 참** 이다
(저장된 `priceKrw` 를 문장으로 옮기기만 한다 · 곱셈 0).

## 5. 계약 (구현 시 같이 넣는다 · 네트워크 0)

```
A-1 🔴 지역 ≥2 + 통화 1종 ⟹ 문구가 **선다** (Smallable 모양)
A-2 🔴 통화 2종 이상 ⟹ 문구가 **서지 않는다** (louisemisha·bobochoses 모양 · **거짓 방지**)
A-3 🔴 지역 ≤1 ⟹ 문구가 **서지 않는다** (en-int 단독 · 「모르면 말하지 않는다」)
A-4 🔴 `en-int` 는 지역으로 세지 않는다
A-5 🟢 통화 글자가 **관측에서 온다** — EUR 단일이면 EUR, GBP 단일이면 GBP
B-1 🔴 문구에 「배송 가능」 어휘가 **0** 이다(검증 안 된 사실 금지)
B-2 🔴 문구에 환율/환산 수치가 **0** 이다
B-3 🔴 판매처명·대표금액 칸이 카드 입력에 **여전히 없다**(입력 4칸 불변)
C-1 🟢 **마운트 DOM** 으로 — 문구가 **줄 목록보다 앞** 에 선다(Render PASS ≠ 소스 PASS)
C-2 🟢 기존 회귀 보존 — `observedPrice`/`krwEquivalent` 문자열 **불변**
음성대조 — M1 조건을 「통화 1종」만으로 약화(A-3 FAIL) · M2 「지역」에 int 포함(A-4 FAIL) ·
          M3 문구를 리터럴 EUR 로 고정(A-5 FAIL) · M4 문구를 무조건 렌더(A-2 FAIL)
```

## 6. 🔴 측정불가 · 범위 밖

```
🔴 **실제 따져 화면은 CTO 가 볼 수 없다** ⟹ 화면 축은 **마운트 DOM** 이다.
   「Production UI PASS」로 적지 않는다 — **CEO 확인 1회로만** 닫힌다.
🔴 §3-1 조건은 **현재 판매처 8곳**에서 검증했다. 새 판매처가 늘면 그 분모가 바뀐다 —
   🔴 「모든 판매처에서 맞다」로 적지 않는다.
🔴 「통화가 한 종류다」가 곧 「표시 계층이다」를 **증명하지 않는다** — 증명은 PHASE 2-B 의
   단일 환율 측정이고, 이 조건은 **그 성질과 상관이 높은 관측 신호** 다.
   🟢 그래서 문구가 말하는 것도 「현지통화가 아니다」까지이고 「사이트가 환산한다」는
   **말하지 않는다**(그건 Smallable 에서만 측정된 사실이다).
🔴 배송 가능 여부 · 원본가 행 부재는 **백로그** 다(§C) — 이 작업에서 손대지 않는다.
```
