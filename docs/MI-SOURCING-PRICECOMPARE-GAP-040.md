## §4 연결하려면 넘어야 할 벽이 **셋** 이다 (실측)

```
① 목적      매입처(어디서 사올지) ↔ 동일상품 판매처(시장가) — **제품 정책**
② 키        sourcing_candidates 는 **product_id**, 가격비교는 **snapshot_id** — 입자가 다르다
③ 🔴 통화   실측값 `currency = "₩"` — **ISO 코드가 아니라 기호** 다.
            가격비교 통화 게이트는 `currency === "KRW"` 를 요구하므로
            **연결해도 이 값으로는 통과하지 못한다.**
```
🔴 ③은 이번 추적에서 처음 드러난 **구체적 데이터 결함** 이다(CEO 가 넣은 두 건 모두).
