`folkberlin.com` 후보 설명문 **전문** 을 읽었다:
```

  @301 「The **Gray Label** logo embroidery」
  @598 「About the Brand **Gray Label**」
  @703 「Founded by Emily **Gray** in 2011」   ← 🔴 **창업자 이름** · 뒤에 마커 명사가 없다

🔴 그래서 **브랜드 표지 명사 사전만으로는 @703 을 막을 수 없었다**(실측 · 가드 통과).
🟢 **정답은 사전이 아니라 「선언된 색상 자리」** 였다 — CPO 조건(「실제 색상 Blue Moon 은

```

  ① 원문에 `Colour:` / `Color:` / `색상:` / `컬러:` **선언 자리** 가 있으면 **그 값만** COLOR 로 쓴다
  ② 색상 토큰 바로 뒤가 브랜드 표지 명사(`label`·`logo`·`brand`·`studio` …)면 쓰지 않는다
