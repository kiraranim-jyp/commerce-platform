## 3. 🔴🔴 **그래서 진짜 결함은 이것이고, 내 작업이 만들었다**

```
기존 구역   「**🌐** 글로벌 시장 가격」   EUR 40.00  +  ≈ ₩59,960
내 구역     「**🌐** 해외 참고가격」      EUR 40     (환산 없음)
                ↑ **같은 🌐 아이콘 · 같은 상품 · 같은 EUR 40**
```

🔴🔴 **두 구역이 같은 아이콘으로 같은 금액을 말한다.** 셀러는 둘을 **한 구역으로 읽는다** —
CEO 가 정확히 그렇게 읽었고, 그러면 「해외 참고가격이 환산값을 보여준다」가 된다.

🔴 **그 아이콘 충돌은 WU-049 가 `🌐` 를 고르면서 생겼다 — 내 작업이다.**
🔴 WU-049/056 의 테스트는 **내 블록 안** 만 봤다. 「옆 구역과 구분되는가」는 **단언이 없었다.**
🟢 그것이 이번 FAIL 이 드러낸 공백이다 — 블록 단위 검증이 **화면 단위 혼동** 을 못 잡았다.

## 4. 🔴 최소 수정 선택지 (CTO 가 고르지 않았다 · CPO 판정)

```
⒜ 🟢 **내 블록의 아이콘/제목을 바꿔 충돌을 없앤다**  ← 가장 작고, 내가 만든 충돌을 내가 없앤다
   예: 「🧾 해외 동일상품 참고가격」 / 「🔎 해외 후보 가격(이번 확인)」
   영향: 운영 1상수 · WU-049 계약 중 제목 단언 1건 갱신 필요 · 환산 로직 **무변경**
⒝ 🔴 기존 「🌐 글로벌 시장 가격」의 `krwEquivalent` 를 제거/숨긴다
   🔴 **장기 운영 중인 의도된 설계** 다(주석 명시) · 원가 판단 축에 영향 · **제품 정책**
⒞ 🟡 둘 다 유지하고 내 블록에 「원본/글로벌 시장 카드와 다른 값입니다」 구분 문구 추가
   🔴 화면이 길어지고, 「왜 둘이 있나」를 문구로 때우는 쪽이다
```

🟢 **CTO 권고는 ⒜** 다 — 환산 정책을 건드리지 않고, 충돌의 **원인** 을 없앤다.
🔴 그러나 구역 제목은 셀러가 읽는 어휘라 **제품 정책** 이고, CPO 가 문구를 정해야 한다.

🔴 그리고 ⒜ 를 택하면 **블록 간 구분을 단언하는 테스트** 를 같이 넣어야 한다 —
「한 화면에 같은 아이콘으로 시작하는 가격 구역이 둘 이상 없다」. 그 공백이 이번 FAIL 의 원인이다.
