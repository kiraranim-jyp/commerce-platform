# 🟡 CEO Action — **첫 실제 상품 등록 1건** (한 번에 끝나는 순서)

> 🔴 이 문서는 **코드 검토나 기술 판단을 요구하지 않는다.** 필요한 것은
> **실제 사업 데이터 입력 7칸 + 실등록 승인** 둘뿐이다.
> 🟢 CTO 가 별도로 받아야 할 데이터는 **없다** — 아래 그대로 하면 끝난다.
>
> 🔴 소요: 설정 입력 약 5분 + 등록 1건 약 3분.

---

## 1. Settings 입력 화면 URL

```
판매자 정보   https://ttaejyo.vercel.app/settings?tab=seller
배송 프로필   https://ttaejyo.vercel.app/settings?tab=shipping
```
🟢 `?tab=` 를 붙이면 그 탭이 **바로 열린다**(탭을 찾아 누르지 않아도 된다).

---

## 2·3. 7개 항목 — **위치와 넣을 값**

### ⒜ Settings 에서 넣는 5칸

| # | 항목 | 화면 | 칸 이름(그대로) | 넣을 값 |
|---|---|---|---|---|
| 1 | 출고 택배사 | `?tab=shipping` | **「기본 택배사」** | 실제 쓰는 택배사를 목록에서 고른다 |
| 2 | 제조사 | `?tab=seller` | **「제조사」** | 🔴 **Bobo Choses** 또는 실제 제조사명 |
| 3 | A/S 책임 업체명 | `?tab=seller` | **「A/S 책임 업체명」** | 🔴 **대표님 사업자명**(판매 주체) |
| 4 | A/S 전화번호 | `?tab=seller` | **「A/S 전화번호」** | 🔴 **실제 연락 가능한 번호**(숫자·`-`·`+` 만) |
| 5 | 품질보증기준 | `?tab=seller` | **「품질보증기준」** | 예) `관련 법 및 소비자분쟁해결기준에 따름` |

🔴 **2~5 는 제가 지어낼 수 없습니다.** 그 값이 그대로 **공개 상품의 신고·표시 정보**가 되기 때문입니다. 대표님이 쓰실 실제 값을 넣어 주십시오.
🟢 한 번 넣으면 **이후 모든 상품에 재사용**됩니다(상품마다 다시 묻지 않습니다).

### ⒝ 상품 화면에서 넣는 2칸

| # | 항목 | 위치 | 칸 이름 | 넣을 값 |
|---|---|---|---|---|
| 6 | 소재 | 상품 화면 → **상품정보** | **「소재」** | 🟢 **면 100%** — 원상품 페이지 표기를 제가 확인했습니다(한 번 확인만 해 주십시오) |
| 7 | 기본 재고 | 상품 화면 → **상품정보 → 재고** | **「기본 재고수량」** | 예) `10` — 옵션별 재고를 원본에서 못 읽어 이 값으로 조합이 복구됩니다 |

🔴 재고를 `0`/`999` 같은 임의값으로 넣지 않습니다 — 실제 보유/판매 가능 수량을 넣어 주십시오.

---

## 4. 저장 후 validation 재확인 방법

```
상품 화면 → ③ 등록 준비 → [등록 준비 확인] 버튼
```
🟢 **기대 결과**: 누락 항목이 **0** 이 된다(지금은 **7개**).
🔴 7개 중 남는 것이 있으면 **그 칸 이름이 화면에 그대로 적혀 있습니다** — 그 칸만 채우시면 됩니다.

---

## 5. 등록할 테스트 상품 — 🔴 **반드시 «새로 분석»** 해야 합니다

```
https://ttaejyo.vercel.app/pipeline
   → 원상품 URL 칸에 아래를 붙여넣고 분석을 시작합니다

https://bobochoses.com/ko-kr/products/b226ac009-hug-hairy-monster-t-shirt
```

🔴🔴 **기존에 열려 있던 같은 상품을 쓰지 마십시오.** 저장된 스냅샷은 **브랜드가 빈 채로**
저장돼 있어(WU-134 수정 전) 등록 payload 의 브랜드가 비어 버립니다.
🟢 **새로 분석하면** 브랜드가 `Bobo Choses` 로 채워지는 것을 제가 실측 확인했습니다.

🟢 이 상품은 WU-134 에서 **실제 동일상품 3건과 해외 가격비교 4건**이 확인된 그 상품입니다.

---

## 6. 등록할 채널

```
🟢 스마트스토어(SmartStore) **하나만**
```
🔴 롯데ON 은 **자격증명이 등록돼 있지 않습니다**(DB 실측) · 쿠팡은 이번 범위가 아닙니다.

---

## 7. 등록 버튼까지의 정확한 순서

```
① /settings?tab=shipping  → 「기본 택배사」 입력 → 저장
② /settings?tab=seller    → 제조사 · A/S 책임 업체명 · A/S 전화번호 · 품질보증기준 입력 → 저장
③ /pipeline               → 위 원상품 URL 붙여넣고 **새로 분석**
④ 분석이 끝나면 **상품정보** 에서 「소재」 = 면 100% 확인 · 「기본 재고수량」 입력
⑤ ② 시장 판단 에서 **📊 동일상품 가격 비교** 에 해외 행이 보이는지 한 번 봅니다(확인만)
⑥ ③ 등록 준비 → 등록할 커머스로 **스마트스토어** 선택 → [등록 준비 확인]
   🔴 누락 0 이 아니면 거기서 멈추고 적힌 칸을 채웁니다
⑦ ④ 커머스 등록 → [선택한 커머스 등록] → 확인 모달에서 최종 승인
```

---

## 8. 등록 후 확인해야 할 결과

```
🟢 화면에서
   · 등록 성공 표시 + **상품번호(상품 ID)** 가 보인다
   · 등록 이력에 성공 1건이 남는다

🟢 스마트스토어 센터에서(실제 채널)
   · 상품명        Hug Hairy Monster T-shirt 계열
   · **브랜드      Bobo Choses**        ← 🔴 이번 수정의 핵심 확인 지점
   · 대표이미지 + 추가이미지가 올라갔다
   · 판매가 · 재고 · 옵션 조합이 입력대로다
   · 상세정보(상세페이지)가 들어갔다
   · 고시정보(소재 · 제조사 · 품질보증 · A/S)가 채워져 있다
```

🔴 **정상인데 FAIL 로 보이기 쉬운 것 둘**
```
⒜ 「🇰🇷 국내」 가격비교가 **비어 있는 것은 정상** 입니다 — 국내 축은 별도 개선 대상이고
   이번 범위가 아닙니다(해외 가격비교만 보시면 됩니다).
⒝ 후보 목록에 「판정 보류」 행이 있는 것도 **정상** 입니다 — 동일상품으로 확정된 것만
   가격비교에 올라가고, 보류는 아래 검토 구역에서 눈으로 판단하시는 몫입니다.
```
