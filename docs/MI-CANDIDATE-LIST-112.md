## 2. 🔴🔴 **운영 산출이 아니라 「후보 전수」를 냈다** — 이유를 적는다

```

🟢 그래서 **후보를 전수로 싣고 운영 판정값을 «같이» 보여준다**(verdict · tier · 「이 샵은 제외됨」).
🔴 그리고 **판정하지 않은 후보의 `priceTier` 는 null 로 뒀다** — 지어내지 않았다
   (WU-085/096 에서 두 번 틀린 그 행위 · WU-097/098 계약).
🟢 화면에 「우리 시스템 줄은 참고용이고 대표님 판정이 정답」이라고 **적었다**.
```
