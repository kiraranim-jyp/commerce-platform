## 3. 🔴🔴 **AI 후보 공급을 넣을 자리는 «한 곳» 으로 확정됐다**

```

🔴 자동으로 채우는 길 셋은 **전부 정책 HOLD** — Gemini flag(비용) · 외부 AI API(전면 제외) ·

⟹ 🟢 **설계상 더 만들 배선이 없다.** 공급원 하나가 열리면 **그 자리에 값을 넣기만** 하면
   국내·해외가 같은 흐름으로 MI→시장가격 비교까지 간다(코드 경로는 이미 있다).
```

## 4. 🟢 그래서 **최종 흐름이 하나로 적힌다**(제품 기준선)

```
① 셀러 입력 — **원상품 URL 하나**
② 자동 후보 탐색 — 국내 + 해외   ← 🔴 **공급원이 정책으로 열려야 하는 자리**
③ 상품 페이지 확인(facts)
④ MI — SAME / SIMILAR / DIFFERENT
⑤ **시장 가격 비교 «한 구역»** — 🇰🇷 국내 / 🌎 해외를 그 안에서 나눈다
⑥ (선택) 대표님 판정 → **GT 누적** → MI 개선 데이터
🔴 ⑤ 안에서만 금액을 보여준다 — **별도 「참고가격」 패널을 만들지 않는다**

```
