그래서 이번 목록은 **넷을 동시에** 지킨다:

```

③ 행마다 **판정 라벨 + 그 판정의 note(=제외 이유)**
④ 구역에 **「가격비교에 사용되지 않습니다」** 명시
```

## 3. 🟢🟢 조사 — **데이터는 «이미» 화면까지 오고 있었다**

```

   ↓
```

하나** 였다. ⟹ **데이터 전달 경로 수정이 필요 없었다**(CPO §7 의 허용 범위를 쓰지 않았다).

`facts.brandModelCode` 가 **화면까지 온다**. 🔴 **UI 타입이 선언하지 않아서** 못 쓰고
있었을 뿐이다 ⟹ 선언 한 칸 + 전달 한 줄(**서버 0 · 판정 0**).

### 🔴 ①의 핵심 — 정책을 **다시 매기지 않았다**

```ts
export function selectOtherCandidates(rows) {
  return rows.filter((r) => !isVisualCheckTier(r.tier)).sort(...);
}
```
🟢 `isVisualCheckTier`(카드 정책)는 **한 글자도 안 바꿨다**. 추가된 것은
**「그 정책을 통과하지 못한 나머지」를 접어서 보여주는 자리** 하나다.
🔴 그리고 `ALL_TIER_ORDER` 를 **따로 만들었다** — 기존 `DEFAULT_TIER_ORDER` 에는
`UNKNOWN`/`CONFLICT` 가 **없어서** `indexOf` 가 `-1` 을 주고 **제외 후보가 맨 위로
올라왔을 것** 이다.

### 🔴 ②의 범위 — 링크만 뺐다
`brand`/`title` prop 은 **지우지 않았다** — 헤드라인 분기와 상위 호출부가 쓴다.
