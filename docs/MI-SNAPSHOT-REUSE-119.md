# [WU-119 STOP 보고]

## 1. 🟢 먼저 — **transient 계약은 「무조건 저장 금지」가 아니다**(원문 확인)

```
transient-candidates.ts 머리 주석
  「🔴 **저장하지 않는다.** DB 클라이언트를 import 하지 않는다(테스트가 그것을 잠근다)」
  ← 🟢 이것은 **이 모듈** 에 대한 말이다(leaf · 의존 0)
저장 차단의 실제 지점(주석이 명시)
  ⒜ `upsertDomesticProductLink` **앞 가드**
  ⒝ `recordDomesticSourceCheckAttempt` 래퍼
  ⟹ 🟢 막는 대상은 **`domestic_product_links`(= 판정·가격 경로)** 다
🟢 그래서 「스냅샷 어딘가에 URL 을 둔다」가 **그 계약을 직접 깨는 것은 아니다**.
```

## 2. 🔴🔴 그러나 **§12-0 과는 정면으로 만난다** — 그래서 STOP 이다

```
§12-0 「현재 제품의 목표가 «아닌» 것 일곱」에 **「외부 URL 영구 저장 ❌」** 이 있다.
🔴 스냅샷 행은 **세션이 끝나도 남는다**(`product_snapshots` 는 영속 테이블이다)
   ⟹ 범위를 상품 하나로 좁혀도 **「외부 URL 을 영구 저장한다」는 사실 자체는 성립한다**.
🔴 즉 CPO 가 STOP 조건으로 적어 둔 **바로 그 경우** 다.
```

## 3. 🔴 그리고 **담을 칸이 없다** — 새 schema 가 필요하다

```
product_snapshots 칸 전수(WU-021 에서 information_schema 로 읽은 그대로):
  id · source_url · title · thumbnail_url · status · workspace(jsonb) ·
  created_at · updated_at · last_opened_at · job_key · workspace_id · product_id
🔴 후보 URL 을 담는 칸이 **없다**. 선택지는 둘뿐이고 **둘 다 정책 결정** 이다:
  ⒜ `workspace` jsonb 안에 넣는다 — 🔴 그 칸은 `canonicalProduct` 등 **상품 사실** 의 자리다.
     후보 URL 목록을 섞으면 그 칸의 의미가 둘이 된다(헌장 「칸의 owner 를 흐리지 않는다」).
  ⒝ **새 칸/새 테이블** — 🔴 DB migration 이고 헌장이 「혹시 모르니까 migration」을 금지한다.
🔴 그리고 CTO 는 **로컬에서 운영 DB 에 쓸 수 없다**(service-role 부재 · WU-011 실측) ⟹
   이 구현의 검증은 **배포 후 Production 쓰기** 를 요구한다.
```

## 4. 🟡 그래서 **CPO 가 열어야 하는 것이 정확히 무엇인지** 만 적는다

```
① §12-0 의 「외부 URL 영구 저장 ❌」에 **예외 한 줄** 을 둘 것인가 —
   예: 「**사람이 SAME 으로 확정한 후보 URL** 은 **그 스냅샷 안에서만** 보관하고
        **다음 조사의 입력 후보로만** 쓴다. 가격·판정·다른 상품에는 쓰지 않는다」
② 그 보관을 ⒜ `workspace` jsonb 에 둘지 ⒝ 새 칸으로 둘지(**schema 결정**)
🔴 ①이 없으면 ②를 할 수 없고, ②가 정해지지 않으면 구현이 임의가 된다.
🔴 **CTO 는 둘 중 아무것도 고르지 않았다.**
```

## 5. 🟢 STOP 이어도 **잃은 것이 없다** — 효과는 이미 측정돼 있다

```
WU-118 실측 — Human SAME URL 을 다시 투입하면 **19/19 전건이 후보로 등록된다**(탈락 0).
⟹ 🟢 그래서 「재사용이 되면 국내/해외 후보가 몇 개 사는지」는 **이미 아는 값** 이다:
   재사용 시 국내는 S1 **2 → 최대 3**(beaumonde·biskuit·그 밖 SAME 국내 후보 수만큼) ·
   해외는 **⑧ 게이트·샵 2순위로 사라진 4건이 입력으로 되살아난다**
   🔴 단 그 4건은 **다시 같은 게이트를 만난다**(P2/P3 보류) ⟹ 화면 증가는 **보장되지 않는다**
🔴 그래서 「스냅샷 재사용만으로 국내 후보가 늘어난다」로 **적지 않는다** —
   국내 병목은 ①(AI 가 국내 상세 URL 을 거의 주지 않는다)이고 재사용은 **그 6·4개를 보존** 할 뿐이다.
```
