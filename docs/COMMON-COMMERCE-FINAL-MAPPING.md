### 🔴 재분류 — CPO 초안과 갈리는 둘

CPO 초안은 **원산지·브랜드를 `CHANNEL_MAPPING_ONCE`** 로 두었다. **코드를 대조한
결과 그 둘은 「1회」가 아니다.**

```
출고지    판매자가 «한 번» 정하면 모든 상품이 같다        → 1회가 맞다
원산지    상품마다 다르다 (이 상품 스페인 · 다음 상품 이탈리아)
브랜드    상품마다 다르다 (Bobo Choses · Pickles …)
          → «1회 매핑» 이 성립하지 않는다
```

그러면 무엇인가 — **택배사와 같은 모양**이다. 공통에 «이름» 이 있고 채널이
«이름 목록» 을 준다.

| | Common | 채널 목록 | 지금 |
|---|---|---|---|
| 원산지 | `countryOfOrigin` 「스페인」 | 89 `OPLC_CD` (선택기 있음) | 셀러가 고른다 |
| 브랜드 | `brand` 「Bobo Choses」 | 204 — 🔴 **부르는 코드가 없다** | 셀러가 **적는다** |

**판정: 둘 다 `COMMON_AUTO 후보` — 단 전제가 있다.**

```
원산지  89 OPLC_CD 의 cdNm 이 「스페인」처럼 국가명인가?  → 🟡 UNKNOWN
        (화이트리스트에 있어 부를 수는 있다. 응답을 본 적이 없다)
브랜드  204 를 부르는 코드 자체가 없다 → 🔴 구현 전 조사 필요
        브랜드명이 채널에서 유일한가도 모른다(동명 브랜드)
```

🔴 **그래서 지금 자동화하지 않는다.** 분류만 바로잡아 둔다 — 「1회 매핑」으로
설계하면 상품마다 다른 값을 한 번만 고르게 만드는 **잘못된 구조**가 된다.
