## 3. 🇰🇷 국내 URL — **이것이 유일하게 큰 차이다**

```
테스트 1   🇰🇷 **1**   (Main Story `miniboutique.co.kr` 하나)
테스트 2   🇰🇷 **8**   (6개 상품에서 나왔다)
   BOSS                  11st.co.kr ×2 · croket.co.kr
   Main Story            miniboutique.co.kr
   Mini rodini           kream.co.kr
   Damarindo / Racchetto lfmall.co.kr
   Trattino Short        **sergiotacchini.co.kr**  ← 🟢 브랜드 **한국 공식몰**
```

🔴🔴 **그러나 그 8건을 「국내 후보 8」로 읽으면 안 된다** — **정책·모양 축을 아직 안 지났다**:
```
11st.co.kr · kream.co.kr   → 🔴 등록부 `NOT_AVAILABLE`(약관) ⟹ **정책 게이트가 막는다**
11st `search…?kwd=` · lfmall `app/search/result/…`
                           → 🔴 **검색 결과 페이지** 이지 상품 상세가 아니다
🟢 상품 상세로 보이는 것 — `miniboutique.co.kr/product/…` ·
   `croket.co.kr/brand/…`(브랜드 목록일 가능성) · `sergiotacchini.co.kr/display/…`
⟹ 🔴 **이번 측정은 §15 가 요구한 「건수 비교」까지** 다. Crawl/Evidence/Identity 는
   **돌리지 않았다**(그 라우트는 URL 만 돌려준다) ⟹ 「국내 후보가 8 늘었다」로 적지 않는다.
```

🔴 그리고 **SP-10 이 측정한 실행 간 변동(같은 질의 URL 겹침 3~30%)** 이 그대로 유효하다 ⟹
**1회 관측** 이므로 `+11` 과 `1 → 8` 의 **일부는 변동 폭 안** 일 수 있다.
🟡 다만 🇰🇷 는 **6개 상품에 걸쳐** 나왔고 테스트 1 은 **1개 상품뿐** 이라 방향은 일관된다.
