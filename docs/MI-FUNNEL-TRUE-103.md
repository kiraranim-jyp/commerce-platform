## 2. 여섯 단계 — **동일상품만 따라갔다**

### S1 (동일상품 2건)
```
🟢 bobochoses.com/**ko-kr**/products/b226ac010-…   → 추출 🟢 → 풀 통과 → **JUDGED**
🔴 search.shopping.naver.com/search/all?query=B226AC010 → **② 추출 탈락**
   🟢 **올바른 탈락** 이다 — 그것은 **검색 결과 페이지** 이고 상품 URL 이 아니다
⟹ ② 소실 **1**(올바름) · ③④⑤ 소실 0 · ⑥ 소실 **0** · **JUDGED 1**
```
🔴 통과한 1건이 **같은 샵의 다른 로케일**(`/ko-kr/`)이다 — 🟢 WU-008A 가 「로케일은 다른

### S2 (동일상품 3건)
```

🟢 biskuit.kr/…b226ac009/…              → 추출 🟢 → 풀 통과 → **JUDGED**
⟹ ② 소실 **0** · ③④ 소실 **1**(UNREACHABLE) · ⑥ 소실 **0** · **JUDGED 3**
```

## 3. 🔴🔴 그래서 최초 손실 지점은 — **단계가 아니라 «비율» 이다**

```
S1  AI 36건 중 동일상품 **2**(5.6%) · S2  29건 중 **3**(10.3%)
⟹ 🔴 AI 가 가져온 URL 의 **90% 이상이 다른 상품** 이다
🟢 그리고 동일상품이 들어오면 ②~⑥ 이 **1건씩만** 잃는다(②는 검색URL·③④는 UNREACHABLE)
```

🔴 **「최초 손실 지점」을 한 단계로 지목할 수 없다** — 단계별 소실이 **0~1건** 이라
표본이 그 질문에 답할 만큼 크지 않다. 🟢 그러나 **⑥(= WU-096 이 「최초 병목」이라 한 곳)에서
동일상품이 하나도 죽지 않았다**는 것은 **확정** 됐다.
