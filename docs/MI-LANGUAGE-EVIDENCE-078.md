```

① 🔴 **언어는 애초에 병목이 아니었다** — `NO_TITLE_OVERLAP` 4건 **전부** 한글 제목에

## 2. ② 음역 축 — 결정론적 · 외부 API 0

```
한글 음절은 **산술로** 분해된다 — (code − 0xAC00) → 초성/중성/종성.
사전도 모델도 번역 API 도 쓰지 않는다. 🔴 **테스트 로컬 함수** 이고 운영에 넣지 않았다.
정규화는 **일반 외래어 규칙만** — sh/sy→s · ch→c · c→k · 연속 중복자 축약 · 모음 제거.
🔴 이 표본의 단어에 맞춘 규칙은 넣지 않았다(N=4 에 맞추면 과적합이다).
```

🔴 DIFFERENT **0**. ⟹ 이 표본에서 오탐 **0/3**.

### 🔴 측정 중 **제어문자 버그 두 개** 를 잡았다 (숫자가 바뀌었다)

```
⒜ 정규식에 **백스페이스(0x08)** 가 박혔다 → 품번 탐지가 **전건 null** 이었다
⒝ 중복자 축약의 역참조 자리에 **0x01** 이 박혔다 → skeleton 이 깨져

🔴 원인은 쉘/파이썬 편집 층의 이스케이프다. 🟢 **튜닝이 아니라 버그 수정** 이다 —
   고치기 «전» 숫자(C15 0 · C47 1)를 그대로 남긴다.
🟢 그 뒤로 정규식 역참조를 **쓰지 않는다**(배열 필터로 대체).
