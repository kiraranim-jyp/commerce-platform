검토 대상 11건 · 대표님 확인 1회

왜 이 화면인가

  • 지금까지는 코드가 이미 가진 칸(브랜드·색상·소재)만 파고들었습니다. 대표님 말씀대로 상세설명 하나만 제대로 읽어도 필요한 정보가 대부분 나올 수 있습니다.
  • 그래서 이 화면은 상세설명 전문을 그대로 보여 드리고, 사건마다 여섯 가지만 묻습니다.
  • 왼쪽 번호 ①–⑥ 은 증거를 보는 순서입니다. 후보 쪽이 빈 칸은 줄을 그어 두었으니, 사슬이 어디서 끊기는지 바로 보입니다.
  • 시스템 판정은 참고용입니다. 대표님 판단이 기준이고, CTO 는 이 화면에서 아무 판정도 채우지 않았습니다.

먼저 알려 드릴 한계 셋

  • 현재 브랜드 추출기는 상세설명을 읽지 않습니다. 그래서 「설명에서 브랜드를 찾은 건수 0」은 효과가 0이라는 뜻이 아니라, 읽는 경로가 아직 없다는 뜻입니다.
  • 형태·색상·소재·세트 구성도 상세설명에서 추출하는 경로가 없습니다. 빈 칸을 「그 상품에 없다」로 읽지 말아 주십시오.
  • biskuit · luxboy · bornyesterdaykids 는 이 묶음에 들어 있지 않습니다 (다른 조사에서 쓴 라벨입니다). 분모는 11건입니다.
