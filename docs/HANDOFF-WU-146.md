## 🔴 이 WU 가 실제로 고친 것 — **「결론이 결론이 아니었다」**

```
WU-145 가 만든 한 줄:
  「판매가격 판단: 확인된 동일상품 가격을 기준으로 위 가격대를 시장 기준으로 참고할 수 있습니다.」
🔴🔴 그 문장은 **상태와 무관하게 늘 같았다** — 가격이 하나든 셋이든, 국내가 0 이든,
   가격을 못 가져온 동일상품이 있든 **똑같이** 적혔다. ⟹ 결론이 아니라 **안내문** 이다.
🟢 CPO STEP 2: 「**동일상품 3곳 / 가격 USD 58** 만 보여주는 것은 «데이터 표시» 다.
   우리가 필요한 것은 **셀러 판단을 돕는 결론**」.
```

🟢 그래서 **상태 기계** 를 만들었다 — `marketDecisionLines(j)`:

| kind | 조건 | 문장 |
|---|---|---|
| `NO_SAME` | 확정 동일상품 0 | 「아직 동일상품으로 확정된 판매처가 없습니다.」 + 어디서 보는지 |
| `SAME_NO_PRICE` | SAME 있고 가격 0 | 「동일상품은 확인됐지만 확인된 판매가가 아직 없습니다.」 + 링크 안내 |
| `PRICED` (단일) | 통화 1 · 범위 아님 | 「{시장}에서 동일상품 판매가가 확인됩니다.」 + 「확인된 **기준가격**은 USD 58 수준입니다.」 |
| `PRICED` (복수) | 통화 ≥2 또는 범위 | 「{시장} 동일상품 가격이 확인됩니다.」 + 「확인된 가격은 **CAD 64 / GBP 37 / USD 58** 수준입니다.」 |

🔴 **추가 줄 둘**(조건부 · 지어내지 않는다):
```
가격 미확인 SAME 이 있으면  「동일상품은 확인됐지만 일부 판매처의 가격은 직접 확인이 필요합니다.」
🇰🇷 0 **이고 해외에 가격이 있으면**
   「현재 확인된 국내 동일상품 가격은 없습니다.」
   「해외에서 확인된 동일상품 가격을 기준으로 참고할 수 있습니다.」

   없는데 쓰면 그것이 바로 「없는 데이터를 기준으로 만들기」다
```

🔴 **금지(CPO 명시)** — 「시장 평균」·「적정 판매가」·「권장 판매가」·「추천 판매가」.
우리가 가진 것은 **시장 기준가격** 이고 셀러의 **원가·수수료·마진이 없다**(§00-B).

## 🟢 배치 — 결론이 **요약보다 먼저** 다

```
📊 시장 판매 판단
  [🇰🇷 국내 블록]  [🌎 해외 블록]      ← 동일상품/판매중/가격/확인필요 수 + 기준가격
  (시장 미확정 후보 한 줄)
  💡 판매 판단                        ← MARKET_RESULT_HEADING (전 「판매·가격 판단 결과」)
    seller-decision                   ← 🔵 **결론**(상태별 문장) ← 신설 · owner 하나
    market-verdict                    ← 네 상태 라벨(분류어) — 🔴 결론 «뒤» 로 내렸다
    판매중 확인 N곳 · 확인불가 N곳
    판매중 확인 — 🇰🇷 N곳 · 🌎 N곳
    통화별 범위
    판매처 표(🔗 가격 확인 링크)
  (보류 건수 한 줄)
  ▸ MI 상세 분석                      ← 보류 **사유 분포** · 참고가격 블록
```

🔴 **`verdict` 를 결론 앞에 두지 않았다** — 그것은 **분류어** 이고 셀러가 원하는 답은
「그래서 얼마냐」다. 요약을 먼저 읽히게 두면 셀러는 **그 한 줄만 보고 판단한다**(WU-140 교훈).
🔴 **WU-145 의 `market-price-judgement` 는 제거했다** — 두면 결론이 **둘** 이 된다(절대조건 2).
🔴 **판매처 표는 1차에 남겼다** — 절대조건 **6**(「가격 없음 → 실제 candidate URL」)의
링크가 그 안에 있고, 접힘 뒤로 보내면 「확인할 수 있다」가 거짓이 된다.
